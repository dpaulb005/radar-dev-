\noindent The baseband circuitry (video amplifier and filtering, half-rail reference, power input, sync and IF input) was simulated in NI Multisim 14.2 using library parts, one block per card and then all of it on one sheet (card 8). Nothing has been built yet. Plots are in Section~\ref{sec:figs}.

\noindent\textbf{Changes made on card 8:}
\begin{itemize}
  \item Wired U1A's $V-$ and U1B's $V+$ pins. They were left unconnected when the blocks were
        copied onto one sheet, which latched the amp at the rail.
  \item C6 raised from 47\,\textmu F to 3.3\,mF. The half-rail reference was moving with the
        signal and the first stage amplified it.
\end{itemize}

\noindent\textbf{Notes:}
\begin{itemize}
  \item Card 8's analog rail reads 11.49\,V because the TI op-amp model draws 5.7\,mA per amp
        (datasheet: 1.4\,mA typ.). Expected about 11.6\,V on the real circuit.
  \item The op-amp model can't run below about 4.4\,V supply, so power-up starts at 6\,V.
\end{itemize}

\section{Summary}
All cards pass. Card 8 passes after the wiring fix and the C6 change.
