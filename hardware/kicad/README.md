# KiCad schematics — three sheets, three questions

All three are native KiCad schematics (KiCad 7 or 8, symbols embedded, no
libraries to install) and all three are generated by the Python beside them.
Every generator runs the same connectivity self-check before it writes:
no dangling wire ends, no single-pin nets, and the net list saved to
`*_nets.json`.

| sheet | answers | generator |
|---|---|---|
| `radar_flow.kicad_sch` | **How does it all fit together?** Every part in the build, wired to every part it touches, in signal order, with the level on each connection. Start here. | `gen_flow.py` |
| `radar_breadboard.kicad_sch` | **What do I build?** The breadboard at component level, left, and the modules it connects to, right. | `gen_schematic.py` |
| `radar_multisim.kicad_sch` | **What should each part measure?** Five test blocks, each drawn alone with its own sources and every value on the page. | `gen_multisim.py` |

The block numbers are shared between the flow sheet and the Multisim sheet:

| | block | what it is |
|---|---|---|
| 1 | VIDEO AMPLIFIER | 40 µV of audio in, line level out. The other four exist to serve it. |
| 2 | HALF-RAIL REFERENCE | VANA/2, buffered. Block 1 will not bias without it. |
| 3 | 12 V INPUT | D1 reverse protection, then the VANA filter. Everything runs on its output. |
| 4 | SYNC DIVIDER | 3.3 V logic down to 0.3 V for the sound card's right channel. |
| 5 | THE RADAR ITSELF | A behavioural stand-in for the whole RF chain, scaled so SPICE can run it. |

Only three signals cross between blocks: **VANA**, **VREF** and the mixer's
**IF**. The flow sheet draws the two supplies as net labels, so every label
with the same name is one wire, and draws the IF as the single line it is.

## Reading the flow sheet

Top band is the RF front end: bought modules, SMA to SMA, none of which has a
SPICE model at 2.4 GHz, so all of it is measured on the bench rather than
simulated. Block 5 sits under it as the circuit-level stand-in, feeding the
same wire the mixer does, so you can bring the amplifier up and hear a 417 Hz
tone before any RF part arrives.

Build order is on the sheet: 3, then 2, then 1, with 4 and 5 whenever.

```
python3 gen_flow.py         # then open radar_flow.kicad_sch, or look at the PNG
python3 gen_schematic.py
python3 gen_multisim.py
```

Rendered `.svg` and `.png` sit beside each sheet. `*_kicad.svg` is KiCad's own
export from `kicad-cli`; the plain `.svg` is the generator's, which is the one
worth reading.

Not run: KiCad ERC. `kicad-cli` 7 has no `erc` subcommand, so run it from the
GUI if you want it. The generators' own check covers connectivity.
