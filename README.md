# radar-dev — simulation results

Simulation results for my 2.4 GHz FMCW radar, one report per part of the build:

- [`antenna-report.pdf`](antenna-report.pdf): the horn antenna in Ansys HFSS
- [`baseband-report.pdf`](baseband-report.pdf): the baseband circuitry (amplifier and filtering, reference, power, sync, IF input) in NI Multisim

Each one is a pass/fail table followed by the plots. The image files are in [`figures/`](figures/).
Built from the `.tex` files (LaTeX).
